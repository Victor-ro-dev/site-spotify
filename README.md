# Projeto: Replicação do Site do Spotify (2018)

Este projeto é uma **replicação ** do layout do site do Spotify do ano de 2018, utilizando as melhores práticas de **HTML**, **CSS** e **Bootstrap 5**. O objetivo é recriar o design original, garantindo **responsividade** em diferentes tamanhos de tela, com um foco especial na estrutura e estilo visual.

## Diferenciais do Projeto

- Utilização do **Bootstrap 5** para criar uma experiência responsiva e fluida em múltiplos dispositivos, sem comprometer a fidelidade ao design original.
- Combinação do **CSS personalizado** com as classes e componentes do **Bootstrap**, permitindo um equilíbrio entre controle preciso sobre o layout e a eficiência oferecida pelo framework.
- A replicação inclui seções principais do site original, como a home page, menus, rodapé e a apresentação visual dos serviços.

## Tecnologias Utilizadas

- 🔹 **HTML5**: Estruturação semântica do conteúdo.
- 🔹 **CSS3**: Customizações de estilo para garantir a similaridade ao design original.
- 🔹 **Bootstrap 5**: Framework utilizado para criar uma experiência responsiva, com uso de grid, componentes e utilitários.
  
## Funcionalidades

- **Design Responsivo**: A interface se ajusta automaticamente a qualquer tamanho de tela (desktop, tablet e mobile).
- **Layout Fiel**: Replicação detalhada dos elementos visuais do site Spotify em 2018.
- **Navegação Simples**: Links e menus que simulam a navegação real do site original.
